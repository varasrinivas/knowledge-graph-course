# CAPSTONE — Build a Self-Updating Knowledge Graph Pipeline

**Difficulty**: ★★★★☆ (12–18 steps, ~2–3 hours)

## Project Brief
You are the platform engineer for orderflow. Every AI agent your team runs re-derives the repo's structure from scratch, and last month one confidently used the stale WAU definition from an old doc. Your job: give agents a context system that is **structural, narrative, served, and monitored** — the full three-layer stack from the course, with the maintenance machinery that keeps it honest.

You will reuse and wire together every lab solution you built: M01 (graph queries), M06/M07 (bundle), M08 (enrichment hook), M09 (MCP server), M11 (freshness gate).

## Architecture
```
                 ┌─ post-commit hook (M08) ── diff-scoped refresh ─┐
 git commits ────┤                                                 ▼
                 └─ kg_extract / graphify ──► graphify-out/graph.json ──► MCP server (M09) ──► agent
                                          └─► knowledge/ OKF bundle  ──► index.md pre-flight ─┘
 CI: freshness_gate.py (M11) blocks any pipeline step that would trust a stale graph
```

## File Structure
```
sample-project/                    # your working repo (git init'd in M08)
├── graphify-out/graph.json        # structural layer (regenerated by hook)
├── knowledge/                     # narrative layer (refreshed by hook)
├── .git/hooks/post-commit         # M08 hook
└── ci/freshness_gate.py           # M11 gate (copied in)
```

## Build Steps

### Phase 1 — Baseline (steps 1–2)
1. WITHOUT any graph, ask your assistant three questions; record file-reads and tokens for each:
   - Q1 "Who calls decode_jwt, directly and transitively?"
   - Q2 "What breaks if orders_fact gains a column?"
   - Q3 "What is the canonical WAU definition?"
2. Save the numbers in `BASELINE.md`. ✅ Checkpoint: three rows, each with reads + tokens.

### Phase 2 — Structural layer (steps 3–5)
3. Generate the graph (`graphify update .` or `python ../shared_tools/kg_extract.py . --out graphify-out/graph.json`).
4. Verify the ground-truth edges from `sample-project/README.md` all appear.
5. Identify communities and the god node; write one paragraph in `NOTES.md` on what the god node means for refactoring risk. ✅ `shared/auth.py` tops the in-degree list (6), with `shared/db.py` at 5 — in-degree and betweenness rank them differently, which is worth a sentence in your NOTES.md.

### Phase 3 — Narrative layer (steps 6–8)
6. Complete the M07 bundle (5 concepts + index.md + log.md).
7. Lint: `python ../M06-okf-authoring/solution/validate.py knowledge` → 0 errors.
8. Add the attested-computation section to the WAU concept pointing at `metrics.py`. ✅ Lint passes; every concept cross-links both directions.

### Phase 4 — Self-updating (steps 9–11)
9. Install the M08 post-commit hook.
10. Commit a change adding a fake `fraud-check` call to `webhooks.py`; verify the hook refreshes billing-service.md's Dependencies AND appends log.md.
11. Break a concept's frontmatter, commit, and verify the hook FAILS LOUDLY. Fix it. ✅ Both behaviors observed.

### Phase 5 — Serving (steps 12–13)
12. Register the M09 MCP server with your assistant; re-ask Q1–Q3 through it.
13. Record the new file-reads/tokens in `BASELINE.md` alongside Phase 1. ✅ Q1 and Q2 answered in ONE tool call each; Q3 from ONE concept file.

### Phase 6 — Monitoring (steps 14–16)
14. Copy `freshness_gate.py` into `ci/`; run it green.
15. Sabotage: `git commit --allow-empty -m "no rebuild"`, run the gate → exit 1 with an actionable message.
16. Add the gate + lint as a `ci.sh` that a real pipeline would run. ✅ `ci.sh` exits non-zero on either failure.

### Phase 7 — The honest writeup (steps 17–18)
17. Compute your measured improvement multiple from BASELINE.md. Expect single digits on a 15-file repo — BELOW the ~500-file payoff floor. Explain in `NOTES.md` why that is the correct, expected result, and what changes at 5,000 files.
18. Answer the course's defining question in NOTES.md: "How would I detect a stale graph within 24 hours?" — in mechanical terms, referencing your gate.
